# 자재 재고 모니터·예비품 날짜 열 설계

## 목표
예비품 목록에서 날짜를 독립 열로 보여주고, 자재관리 화면에 5종 재고 모니터를 추가한다.

## 화면 변경
- 예비품 표에 `날짜` 열을 추가한다. 수리 진행중이면 시작일, 수리 완료면 완료일을 표시한다.
- 설비 현황의 중복 `설비점검 업데이트` 버튼은 하나만 남긴다.
- 자재관리 표 위에 대 블레이드, 소 블레이드, 페이싱 링, 리테이너 링, 베어링 5개 모니터 카드를 배치한다.
- 각 카드는 클릭하면 수량을 입력하고 저장한다.

## 데이터 흐름
자재 모니터 값은 기존 Supabase `spare_monitor` 테이블을 재사용해 `material_monitor` 키로 저장한다. 초기값은 0이며, 기존 브라우저 저장 데이터와 함께 Supabase에 동기화한다.

## 검증
HTML 중복 버튼 검사, JavaScript 구문 검사, 기존 CRUD 테스트, 자재 모니터 키 렌더링 테스트를 수행한다.
