# 자재·예비품 관리 기능 설계

## 목표

COG Booster 사이트에서 설비 현황과 함께 자재 및 예비품 상태를 확인하고, CSV 업로드 또는 화면 입력으로 관리한다.

## 화면 구성

- 메인 설비 현황 화면의 평균 진동 지표를 제거한다.
- 설비 카드는 데스크톱 기준 가로 5개 × 세로 3줄로 배치한다.
- 왼쪽 메뉴에 `자재관리`와 `예비품관리`를 추가한다.

## 자재관리

자재 목록에 다음 정보를 표시한다.

- 자재명
- 수량
- 납기일
- 상태: `구매중` 또는 `입고완료`

사용자는 자재를 등록·수정·삭제할 수 있고, `materials.csv`를 업로드해 기존 자재명과 일치하는 항목을 덮어쓰거나 새 항목을 추가할 수 있다.

## 예비품관리

예비품 목록에 다음 정보를 표시한다.

- 예비품명
- 수량
- 수리상태: `수리 필요`, `수리 진행중`, `수리 완료`
- 메모

사용자는 예비품을 등록·수정·삭제할 수 있고, `spares.csv`를 업로드해 기존 예비품명과 일치하는 항목을 덮어쓰거나 새 항목을 추가할 수 있다.

## 데이터 형식

`materials.csv` 헤더:

```csv
자재명,수량,납기일,상태
```

`spares.csv` 헤더:

```csv
예비품명,수량,수리상태,메모
```

## 저장 및 오류 처리

- 데이터는 현재 사이트의 브라우저 저장 방식(localStorage)을 사용한다.
- 등록·수정·삭제·CSV 업로드 후 목록과 화면 지표를 즉시 갱신한다.
- 형식이 잘못된 행은 건너뛰고, 반영된 행 수 또는 오류를 알림으로 표시한다.
- CSV 업로드는 기존 목록 전체를 지우지 않고, 이름이 같은 항목만 갱신하며 새 이름은 추가한다.

## 예비품 날짜 및 상태 모니터

- `spares.csv`는 `예비품명,수량,수리상태,수리시작일,수리완료일,메모` 열을 사용한다.
- 수리 진행중 행에는 수리 시작일을 표시하고, 수리 완료 행에는 수리 완료일을 표시한다.
- 예비품 관리 상단에 수리 완료·수리중·수리필요 수량 모니터를 둔다.
- 모니터 수량은 처음에 0으로 시작하고, 숫자를 클릭해 직접 수정할 수 있으며 localStorage에 저장한다.
- 자재와 예비품 목록은 날짜가 있는 항목 중 최신 날짜를 위에 표시하고, 날짜가 없는 항목은 아래에 표시한다.

## 검증 기준

- 메인 화면에 평균 진동 지표가 보이지 않는다.
- 설비 카드가 데스크톱에서 5열로 표시된다.
- 자재와 예비품 메뉴를 열 수 있다.
- 자재·예비품 등록, 수정, 삭제가 동작한다.
- 각 CSV 업로드가 기존 항목 갱신 및 새 항목 추가를 수행한다.
- 새로고침 후에도 저장된 목록이 유지된다.
